HOW IT WORKS
================================================================================

When user clicks "End Call":

1. handleEndCall() is triggered
2. leaveCall() stops all tracks:
   - Disables audio track
   - Closes audio track
   - Disables video track
   - Closes video track
   - Unpublishes tracks from channel
   - Leaves channel
   - Sets state flags to false
3. updateAppointment() marks appointment as "Completed"
4. Router redirects to appropriate dashboard
5. Remote user sees disconnect

Result: Microphone and camera are completely released
